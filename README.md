## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Industry Planner** | Calculate profitability and workforce needs per building type |
| **Production Chains** | Plan input and output chains for complex industrial setups |
| **Trade Planner** | Design export and import trade route configurations per good |
| **GDP Estimator** | Estimate GDP growth from planned industrial expansion |
